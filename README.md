# SQL Server E-commerce Database Management System

## 📌 Project Overview

This project demonstrates the design and implementation of a relational database management system for an E-commerce platform using Microsoft SQL Server.

The database manages customers, suppliers, products, inventory, orders, payments, and sales while maintaining data integrity through relational design and SQL programming.

---

## 🚀 Features

- Customer Management
- Product Management
- Supplier Management
- Inventory Tracking
- Order Processing
- Payment Records
- Sales Reporting
